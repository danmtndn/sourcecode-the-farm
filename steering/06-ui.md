# UI: HP / Damage / Story / Achievements

`obj_game/Draw_64.gml` (Draw GUI):
- Hearts: `global.max_hp=3` circles at (24+i*36,24), red filled if `i<hp` else dkgray. `Keys: N`, `Code: **** (found)` if found.
- Damage: `global.damage_flash=30` on `take_damage()`, red fullscreen alpha 0.45 + `HURT!`. Player `invuln=90`.
- Paper note: `global.note_open` toggled by N (Step) once `code_found!=""` and state==play; auto-opened on paper read. Draw: 0.8-alpha black fullscreen, zoomed paper centered via `draw_sprite_ext` (`global.note_sprite`, default `spr_player` — swap to user's `spr_paper_zoom` later), code drawn ON paper with `draw_text`, `[N] close note` hint. HUD hint `Code found [N view]`.
- Achievement popup: `unlock_achievement("hidden"|"level",label)` sets `ach_text/timer=180`, ini save. Yellow bar top-center.
- States: `intro` black overlay cycling `intro_lines` with ENTER. `dead` shows `YOU DIED / R retry` + `room_restart()`. `outro` shows `outro_lines` + `R restart` to `room_first`.
- `obj_exit/Step_0.gml`: touch player -> `unlock_achievement("level",...)`, if `room==room_last` state=outro else `room_goto_next()`.
- `obj_hidden_item/Step_0.gml`: touch or E within 40px -> `unlock_achievement("hidden",...)`, destroy.
- Edit story only in `obj_game/Create_0.gml: intro_lines/outro_lines`.
