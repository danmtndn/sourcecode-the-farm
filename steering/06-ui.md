# UI: Menu / Pause / Settings / Story / HUD

## Main menu (`rm_menu`, `obj_menu`)
Options: Start Game (room 1) / Settings / Achievements / Quit. W/S or Up/Down
+ ENTER/Space, ESC backs out. Tagline typewriter, controls footer,
achievements x/4 from save. Achievements submenu is a view-only list
(gold label if earned, grey `???` + hint if not, ENTER/ESC backs out);
labels live in `obj_menu/Create_0.gml:ach_list` and MUST match the award
labels in `obj_game` / `obj_hidden_item`.

## Pause (`obj_game` `pause` state, P opens, P/ESC resumes)
Dim panel: Resume / Settings / Quit to Menu (resets run, goes to menu).
W/S + ENTER, Left/Right toggle settings. World frozen: movers hard-exit,
timers/animations hold.

## Settings (menu + pause share the shape)
Music ON/OFF, Sound Effects ON/OFF, Back. Persisted in `thefarm_save.ini`
`[settings]`. Code must route future sounds through `play_sfx(snd)` /
`play_music(snd)` gates (no audio assets in the project yet).

## Story text (`obj_game`, typewriter)
Per-level intro cards (`intro_l1/l2/default` + `story_for_room()`), one final
outro. `type_speed = 2` steps/char with blinking cursor; ENTER completes the
line first, then advances. All story text wraps in a 500px box
(`draw_text_ext`, `_tb_*` vars). Outro reveals line by line. Edit story only
in `obj_game/Create_0.gml`.

## HUD (`obj_game/Draw_64.gml`, skipped in menu)
- Hearts: `global.max_hp=3` circles at (24+i*36,24), red/dkgray. `Keys: N`,
  `Code found [N view]`, `P: pause` hint.
- Damage: `global.damage_flash=30` on `take_damage()`, red fullscreen 0.45 +
  `HURT!`. Player `invuln=90`.
- Paper note: `global.note_open` via N (play only, needs `code_found`);
  auto-opens on read. 0.8-alpha black fullscreen, zoomed paper
  (`global.note_sprite`, placeholder walk art — swap to `spr_paper_zoom`
  later), code drawn ON it, `[N] close note`.
- Achievements: `unlock_achievement("hidden1"|"hidden2"|"hidden3"|"level",label)`,
  `ach_timer=180` yellow bar top-center, ini save per id (`ach_hidden1/2/3`,
  `ach_level`). Legacy `ach_hidden` key is orphaned (unread).
- States: intro cards; `dead` shows `YOU DIED / R retry` + `room_restart()`;
  `outro` shows outro + `R` to menu (`room_first`); exits advance rooms
  (`obj_exit`: touch -> level achievement, last room -> outro else next).
- `obj_hidden_item`: touch or E within 40px -> that level's achievement
  (`hidden1/2/3` picked by `room_get_name`; labels: Farmhouse / Barn Loft /
  Cellar Secret — keep in sync with the menu list), destroy. NOTE: rm_level_3
  has no hidden instance yet, so hidden3 is currently unreachable.
